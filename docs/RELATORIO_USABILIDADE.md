# Relatório de Testes de Usabilidade — Hub do Conhecimento

## 1. Objetivo

Avaliar usabilidade das interfaces **Web** e **Mobile** (login, listagem de questões, filtros e verificação de resposta).

## 2. Metodologia

- **Participantes:** 5 colegas do curso 
- **Plataformas:** Web (Chrome) e Mobile (Expo Go / Android).
- **Tarefas:**
  1. Realizar login.
  2. Navegar até a área de questões.
  3. Filtrar por tópico ou dificuldade (Web).
  4. Responder ao menos 2 questões e verificar o gabarito.
  5. Sair da conta.

## 3. Resultados

| Tarefa | Web | Mobile | Observação |
|--------|-----|--------|------------|
| Login | 5/5 | 5/5 | Fluxo direto |
| Listar / abrir questões | 5/5 | 5/5 | — |
| Filtrar (Web) | 4/5 | N/A | 1 usuário não encontrou o filtro de tópico de imediato |
| Verificar resposta | 5/5 | 4/5 | Mobile: feedback visual reforçado após o teste |
| Satisfação (média 1–5) | 4,3 | 4,1 | — |

## 4. Melhorias aplicadas

- Indicadores de carregamento (ActivityIndicator / estados de loading).
- Mensagens de erro de rede com botão “Tentar novamente”.
- Contador de questão atual no mobile.
- Textos e contraste revisados no login e nas alternativas.

## 5. Conclusão

As interfaces atendem ao uso previsto para estudo de questões de vestibular. As correções listadas foram incorporadas ao código entregue.
